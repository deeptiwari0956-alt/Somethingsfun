# becurious

A personalized AI learning engine: choose any skill, tell us your current level, goal, available time and timeline, and get an adaptive path to capability.

## Included in this MVP

- Modern responsive landing page
- Hero, product preview, how-it-works and CTA sections
- Six-step onboarding flow
- Skill input
- Current experience level
- Goal definition
- Available minutes and days per week
- Desired timeline
- Review step
- Local completion state ready for AI roadmap generation

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
